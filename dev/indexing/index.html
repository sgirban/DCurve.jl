Smart Point Indexing

DiscreteCurve supports zero-copy point extraction, end arithmetic, index collections, and automatic periodic wrap-around on closed curves (c[0] == c[end] and c[end + 1] == c[1]).

using DCurve

# Open curve: standard 1-based bounds checking
c_open = DiscreteCurve([0.0 1.0 2.0; 0.0 2.0 0.0]; closed = false)
c_open[end - 1]

# Closed curve: modular wrap-around via mod1
c_closed = DiscreteCurve([0.0 1.0 2.0; 0.0 2.0 0.0]; closed = true)
(c_closed[0] == c_closed[end], c_closed[end + 1] == c_closed[1])
(true, true)

API Reference

Base.getindex — Method
c[i]
c[indices]

Extract the i-th point (or a collection of points) from a DiscreteCurve as a zero-copy view into c.points.

  • Single integer (c[i]): returns a D-element column view (@view c.points[:, idx]). Supports end arithmetic such as c[end - 1].
  • Index collections (c[1:4], c[[1, 3, 5]], c[(1, 3, 4, 5)], c[:]): returns a D × K submatrix view of the selected points.
  • Boundary behavior:
    • If isclosed(c) == true, indices wrap periodically via mod1(i, npoints(c)) (c[0] == c[end] and c[end + 1] == c[1]).
    • If isclosed(c) == false, out-of-bounds indices throw a BoundsError.
